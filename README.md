🎓 College Finder Bangladesh

A fast, responsive web-based college search tool for exploring XI Class Admission colleges in Bangladesh.

Search and filter colleges using college name, EIIN, GPA, group, district, thana, and gender.

✨ Features

- 🔎 Search colleges by name
- 🆔 Search by EIIN
- 📊 Filter by minimum GPA
- 📚 Filter by group
- 📍 Filter by district
- 🏙️ Filter by thana
- 👥 Filter by gender
- 🔀 Combine multiple filters
- 📱 Mobile-friendly design
- 🖥️ Desktop-optimized interface
- 📋 Responsive college table
- ⚡ Fast client-side filtering
- 🔄 Loading indicator
- 📄 Pagination / load-more support
- 🔗 Quick access to XI Class Admission

🗂️ College Data

The database contains information such as:

Field| Description
District| College district
Thana| College thana
EIIN| Educational Institute Identification Number
College Name| Name of the college
Shift| College shift
Version| Bangla / English
Group| Available group
Gender| College gender category
Min GPA| Minimum required GPA
Own GPA| Own-quota GPA
SQ GPA| Special quota GPA
Available Seat| Available seats

🎯 Purpose

College Finder Bangladesh is designed to make college searching easier for students during XI Class Admission.

Instead of manually checking thousands of colleges, students can quickly narrow down their options using multiple filters.
